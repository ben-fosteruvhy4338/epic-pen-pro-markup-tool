## Overview

Epic Pen Pro provides a Windows desktop overlay for marking up applications, presentations, slides, and shared screens. You can annotate what is already on screen without modifying the underlying application or interrupting your existing workflow.

The tool is suited to demonstrations, instruction, remote collaboration, classroom sessions, and visual note-taking. Its overlay-based workspace combines stylus input with quick controls for writing, highlighting, and erasing, while capture features help preserve presentation content.

A standard annotation session can follow these steps:

1. Launch Epic Pen Pro before beginning a presentation or screen share.
2. Open the desktop window or application that needs markup.
3. Select the pen, highlighter, or eraser from the floating toolbar.
4. Set the desired line thickness and color.
5. Capture or record the screen if you need to save the session.
6. Use configured keyboard shortcuts for frequently used commands.

For example, you can:

- Enter drawing mode
- Annotate slides, charts, or documents
- Keep the session in workspace history for later reference
